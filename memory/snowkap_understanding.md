# Snowkap — Brand, Product & Narrative Understanding (from client documents, June 2026)

## 1. WHAT SNOWKAP IS
**Category:** The **ESG Operating System for enterprises** — explicitly NOT "another ESG reporting tool."
**One line:** Expert advisory + an AI-powered platform + embedded managed support that makes sustainability *possible* — and *provably profitable* — for enterprises that lack the data, systems, and expertise to get there alone.
**Taglines:** "ESG Intelligence For Your Business Growth" · "The only risk is standing still."
**Core belief / governing principle:** "Sustainability can be profitable." → messaging rule: **"Possibility before profitability — always."**

## 2. THE CORE PROBLEM (structural, not ambition)
- **Supply Chain Blindness** — 60–80% of Tier 1–2 suppliers in India/SEA/E. Europe never respond to self-serve questionnaires. Without this data CBAM/CSRD Scope 3/BRSR value chain/EUDR all fail.
- **Fragmented Data** — 5–12 disconnected sources; 70% still on spreadsheets; can't pass assurance.
- **Multi-Framework Burden** — 25+ overlapping frameworks (CSRD, BRSR, GRI, IFRS S1/S2, CBAM, EUDR).
- **No Bridge from Data to P&L** — nobody connects emissions/exposure to EBITDA, cash flow, valuation.
- **Expertise Gap** — mid-market (500–5,000 emp) can't justify Big-4 at $150K–$2M.

## 3. THE THREE PILLARS (primary messaging + product structure)
1. **Advisory** — ESG strategy, regulatory interpretation, ratings optimisation, Sustainability-to-Profitability analysis, capacity building.
2. **ESG Platform** — AI-powered command centre (the real product modules below).
3. **Managed Support** — embedded specialists who *activate suppliers*, coordinate compliance & audits (the work no software can do).

## 4. THE ACTUAL PRODUCT (what is currently under-communicated — must be shown)
### A. IQ ESG Reporting
BRSR · BRSR Core · ESRS · GRI · internal & external assessments · rule-based + manual (expert) recommendations · live ESG scoring & KPI dashboard · maker-checker governance · question assignment & tracking · in-platform query threads · evidence library linked to disclosures · alerts/reminders · progress dashboards · one-click Word/PDF/Excel export.
### B. AI Snowkap
AI Document Repository (central repo + audit log · RARA "Read & Rate" quality scoring · document validation · expiry/renewal reminders) · AI Framework Suggestion Generation (from web + from company's own docs) · AI Benchmarking (peer BRSR textual + graphical comparison) · Chat with Documents (natural-language Q&A with charts).
### C. GHG Carbon Accounting
Bulk templates / guided forms / API ingestion · automated validation & completeness checks · dynamic calculation engine with emission factors · unit standardisation · audit trails & upload logs · AI data extraction from bills/invoices · maker-checker · corporate GHG dashboard · GLEC-compliant transport · waste (generated/disposed) · Scope 3 categories (incl. Capital Goods Cat 2, Cat 3, Cat 11).
### D. Supplier Engagement & PCF (Data Orchestration)
Supplier onboarding · supplier energy-mix dashboard · **PCF calculation** (cradle-to-gate → gate-to-gate) · Scope 3 from real supplier data (up to 5× more accurate than spend-based) · supplier tracker (live status, e.g. done for Daimler).
### E. Platform & Compliance Hub
Guided org onboarding (setup → first report in <2 hrs) · user/account self-service · automated data bridge (GHG → BRSR live, ESRS beta) so one data entry flows across frameworks.

## 5. FOUR PROPRIETARY MOATS
1. **Supplier Trust Score (STS)** — 0–100 credibility score per supplier (5 dimensions), built from 700+ activated suppliers; API-licensable.
2. **Regulatory Mapping Engine** — rules-as-data mapping any data point to ESRS/GRI/BRSR/CBAM/ISSB simultaneously; new regs = config not code.
3. **Industry Emission Factor Library** — 60,000+ custom factors for India/SEA/GCC industries not in IPCC databases.
4. **Sustainability-to-Profitability Modelling** — translates emissions/exposure into EBITDA/cash/valuation; makes the CFO a buyer.

## 6. MANAGED SUPPLIER ACTIVATION — 90-DAY PROTOCOL
- **Phase 1 (Wk 1–2):** Supplier mapping & risk segmentation → Supplier Activation Plan.
- **Phase 2 (Wk 2–4):** Sector/geo-tailored questionnaires mapped to all frameworks; proxy pre-fill; multi-channel (email, WhatsApp, SnowGo app).
- **Phase 3 (Wk 4–10):** Managed onboarding, dedicated specialist, 3-touch protocol; **Day 40 proxy substitution guarantee** (timeline never blocked).
- **Phase 4 (Wk 10–13):** Audit-ready consolidation with full data lineage (primary/estimated/calculated), ESRS E1-6 / CBAM / BRSR annexure — externally assurable.

**New direction:** authoritative, positive, premium.
